# Traefik: two layers

Every public request passes two Traefik instances: the edge one on the VPS, which belongs to Pangolin, and the
internal one on the Docker VM, which also serves the LAN. Both run Traefik v3.

```
internet ─> Traefik on the VPS (Pangolin)  ─tunnel─>  traefik-internal on the Docker VM  ─>  app
LAN      ───────────────────────────────────────────>  traefik-internal on the Docker VM  ─>  app
```

## Edge: Traefik on the VPS

Part of the [Pangolin edge](../pangolin/README.md). It shares Gerbil's network namespace, so the public ports belong to
Gerbil and Traefik listens on them.

| Setting | Value |
|---|---|
| Entrypoints | `web` (:80, ACME HTTP-01 and redirect) and `websecure` (:443, HTTP/3 advertised on 443) |
| Entrypoint middlewares on `websecure` | `crowdsec` (ban enforcement, fail-open) and `security-headers`, so they apply to every route |
| Routes | generated by Pangolin and fetched over its internal API (HTTP provider, polled every few seconds); each resource router carries Pangolin's `badger` middleware for its auth and rule checks |
| Static extras | file provider for the middlewares above ([CrowdSec block](../pangolin/vps/traefik-dynamic-crowdsec.yml)) |
| Certificates | Let's Encrypt per hostname, HTTP-01 |
| Timeouts | 30 min read timeout on `websecure`, so long uploads (photos, video, sync) are not cut off |
| Encoded characters | encoded `/` and `?` allowed in paths (WebDAV and some APIs need them) |
| Security headers | HSTS 2 years with subdomains and preload, `nosniff`, `strict-origin-when-cross-origin`, `frame-ancestors` limited to the own office/cloud app, `Server` and `X-Powered-By` removed |
| Access log | JSON, all status codes, `Authorization` and `Cookie` redacted; read by CrowdSec, rotated daily |

## Internal: `traefik-internal` on the Docker VM

Stack: [stacks/traefik-internal/](../../../stacks/traefik-internal/). It is the single router for the LAN and, through
the tunnel, for the internet; that is what makes "outside = inside".

- **Routes come from one table.** [gen.py](../../../stacks/traefik-internal/gen.py) generates the file-provider
  config from a list of `(subdomain, port, mode)`; Traefik watches the folder and reloads by itself.
  - `open`: the app handles its own login (OIDC, native accounts, sync clients).
  - `auth`: authentik forward-auth in front of everything.
  - `auth-api`: forward-auth except `/api`, for apps whose mobile clients authenticate with an API key.
- **One wildcard certificate** via ACME DNS-01, so the LAN gets valid TLS without being reachable from outside.
- **Real client IPs.** Requests from the tunnel arrive from the newt container; Traefik trusts `X-Forwarded-For` only
  from that Docker range, so apps and their logs see the real client address, and nothing on the LAN can spoof it.
- **Header hygiene.** `aliasHeadersStrategy: delete` drops headers that alias the authentik identity headers
  (`X_authentik_username` vs `X-authentik-username`), so a client cannot smuggle a user name past forward-auth.

## Why two layers

The VPS layer is generic and owned by Pangolin: TLS, CrowdSec, Pangolin's auth. The internal layer holds every
app-specific decision and works without the VPS, so the LAN keeps working when the internet or the VPS is down, and the
public path can be replaced without touching a single app route.
